# 🚀 OpenWrt DoH & SmartDNS Setup (v10.0)

Скрипт автоматического развёртывания отказоустойчивой DNS-системы на OpenWrt с защитой от блокировок, заглушек провайдера и утечек памяти (OOM).

---

## ⚡ Основные возможности

* **⚡ Гибридный DoH (SmartDNS):** 6 параллельных DoH-резолверов с опцией `allservers=1` (выбирается самый быстрый ответ).
* **🌐 Разделение доменных зон (TLD Split):** Запросы к `.ru`, `.su` и `.рф` идут напрямую через Yandex DNS, остальной трафик — через шифрованный DoH.
* **⏰ Синхронизация времени и перехват NTP:** Принудительный редирект порта 123 (NTP) на роутер и жёсткая синхронизация часов для предотвращения сбоев DoH из-за SSL-сертификатов.
* **🛡️ Защита от заглушек провайдера:** Авто-определение IPv4 DNS провайдера и генерация правил `bogus-nxdomain` с ночным автообновлением через Cron.
* **🔧 Защита от OOM и сетевые твики:** Лимитирование памяти (`GOMEMLIMIT` / `GOMAXPROCS`) для `tailscale` и `tg-ws-proxy-go` (если пакеты не установлены — твик автоматически пропускается), а также применение параметров `sysctl`.
* **💾 Безопасность и 1-click откат:** Датированный бэкап UCI-конфигураций и генерация скрипта `/root/rollback-dns.sh` для полного моментального восстановления системы.

---
