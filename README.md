# 🚀 OpenWrt DoH & SmartDNS Optimization Suite v10.6

**Production-ready** скрипт автоматической настройки отказоустойчивой DNS-инфраструктуры для роутеров под управлением OpenWrt. Решает проблемы с блокировками, заглушками провайдеров, GeoIP-фильтрами, рассинхронизацией времени и падением сервисов из-за нехватки ОЗУ.

> ⚠️ **Важно:** Скрипт решает проблемы **DNS-блокировок** и **GeoIP-фильтров**. Для обхода **DPI-блокировок** (YouTube, Discord, Twitter) используйте в связке с [Zapret](https://github.com/bol-van/zapret).

## ⚙️ Архитектура решения

### 1. 🛡️ Гибридный SmartDNS (6 DoH + Yandex)

```
                    ┌─────────────────────────────────┐
                    │        6 SmartDNS параллельно    │
Пользователь ──►    │   (allservers=1 = устойчивость)  │
    │               ├─────────────────────────────────┤
    │               │ 5053: Mafioznik                 │
    │               │ 5054: Comss.one                 │
    ▼               │ 5055: Astrakat                  │
  dnsmasq           │ 5056: Malw.link                 │
  (53)              │ 5057: Comss.ru                  │
    │               │ 5058: VPPay                     │
    │               │ 5059: Yandex (.ru/.su/.рф)      │
    ▼               └─────────────────────────────────┘
 Ответ от самого
  быстрого DNS
```

**Принцип `allservers=1`:** dnsmasq параллельно опрашивает все 6 DNS. Первый ответивший отдаёт результат клиенту. Даже если 5 DNS упали, 1 оставшийся обеспечивает работу.

### 2. 🇷🇺 TLD Split для рунета

Чтобы национальные сервисы (банки, госуслуги) не ломались из-за DoH:
- `.ru` / `.su` / `.рф` → **Yandex DNS** (порт 5059)
- Остальной мир → **6 SmartDNS** через DoH

### 3. 🔒 4 безопасных Bootstrap DNS

Для резолва DoH-серверов используются **только безопасные DNS**, не заблокированные в РФ:

| DNS | IP | Провайдер |
|-----|----|-----------|
| Yandex Primary | `77.88.8.8` | Яндекс (AS13238) |
| Yandex Secondary | `77.88.8.1` | Яндекс (AS13238) |
| AdGuard Primary | `94.140.14.14` | AdGuard (AS42714) |
| AdGuard Secondary | `94.140.15.15` | AdGuard (AS42714) |

**Никаких Cloudflare (1.1.1.1) или Google (8.8.8.8)** — они заблокированы в РФ.

### 4. 🛡️ Защита от заглушек (Anti-Stub)

**Статический список** IP-адресов заглушек провайдеров в `bogus-nxdomain`:
- Ростелеком, Билайн, Дом.ru, МТС, ТТК и др.
- `127.0.0.1` и `0.0.0.0` (от фильтрующих DoH)

Если провайдер возвращает IP заглушки вместо настоящего адреса — dnsmasq отбрасывает такой ответ и берёт реальный IP из DoH.

> **Почему статический, а не автообновляемый?** На сетях с DPI (ТСПУ) провайдеры возвращают **реальные IP** заблокированных сайтов. Автообновление приняло бы их за заглушки и сломало бы доступ.

### 5. ⏱️ Синхронизация времени (NTP)

DoH критически зависит от точного времени (SSL-сертификаты). Скрипт:
- Перехватывает весь NTP-трафик (порт 123) и направляет на роутер
- Устанавливает надёжные NTP-серверы (Cloudflare, Google, NTP Pool)
- Создаёт hotplug для Tailscale (автоматический рестарт при синхронизации)

### 6. 💾 OOM Shield для Go-сервисов

Если установлены `tailscale` или `tg-ws-proxy-go`:
- `GOMAXPROCS=1` — ограничивает CPU
- `GOMEMLIMIT=50-85MiB` — не даёт забирать всю ОЗУ

## 📥 Установка

### Автоматическая установка (одна команда)

```bash
wget -O /tmp/install.sh https://raw.githubusercontent.com/PoTuStoronu222/Openwrt-Smartdns-DoH/main/DONE.v10.6.sh && sed -i 's/\r$//' /tmp/install.sh && sh /tmp/install.sh
```

### Что делает скрипт:

1. ✅ Создаёт **эталонный бэкап** `/etc/config/backup-original` (навсегда)
2. ✅ Создаёт **текущий бэкап** с датой + автоочистка старых
3. ✅ Устанавливает `https-dns-proxy`, `ca-certificates`, `curl`, `bind-tools`
4. ✅ Настраивает 6 SmartDNS + Yandex
5. ✅ Применяет MTU fix, NTP redirect, sysctl tuning
6. ✅ Создаёт скрипт отката `/root/rollback-dns.sh`
7. ✅ Устанавливает утилиты `dns-diag` и `add-stub`
8. ✅ Запускает верификацию

## 🔄 Механизм отката (Rollback)

### Что сохраняется:

| Тип бэкапа | Путь | Описание |
|------------|------|----------|
| **Эталонный** | `/etc/config/backup-original/` | Первый бэкап (исходные конфиги) |
| **Текущий** | `/etc/config/backup-dns-YYYYMMDD_HHMMSS/` | Последний перед установкой |
| **Симлинк** | `/etc/config/backup-pre-dns-v9` | Всегда указывает на последний |

### Что делает откат:

1. ✅ Восстанавливает конфиги из бэкапа
2. ✅ Удаляет созданные файлы (`anti-block.conf`, утилиты)
3. ✅ Сбрасывает `sysctl` в RAM
4. ✅ Перезапускает службы
5. ✅ **Автоочистка:** старые бэкапы удаляются при каждом запуске

### Команда отката (одна строка):

```bash
sh /root/rollback-dns.sh && reboot
```

### Логика выбора бэкапа:

```
if [ есть backup-pre-dns-v9 ]; then
    использовать его
elif [ есть backup-original ]; then
    использовать его
else
    ошибка: бэкап не найден
fi
```

## 🎯 Типичные проблемы и решения

### ❌ YouTube зависает на Android TV через 5-10 секунд

**Причина:** YouTube использует протокол QUIC (UDP 443), который блокируется DPI.

**Решение:** Заблокировать QUIC на роутере:

```bash
uci add firewall rule
uci set firewall.@rule[-1].name='Block-QUIC'
uci set firewall.@rule[-1].src='lan'
uci set firewall.@rule[-1].dest='wan'
uci set firewall.@rule[-1].proto='udp'
uci set firewall.@rule[-1].dest_port='443'
uci set firewall.@rule[-1].target='REJECT'
uci commit firewall
/etc/init.d/firewall restart
```

После этого YouTube переключится на TCP 443, который обходится через Zapret.

### ❌ Telegram web не работает

**Решение:** Направить Telegram через Яндекс DNS:

```bash
for dom in telegram.org t.me web.telegram.org api.telegram.org; do
    uci add_list dhcp.@dnsmasq[0].server="/${dom}/127.0.0.1#5059"
done
uci commit dhcp
/etc/init.d/dnsmasq restart
```

### ❌ Провайдер использует новую заглушку

**Решение:** Добавить IP вручную:

```bash
# Узнать IP заглушки (например, через DevTools → Network)
add-stub <IP-заглушки>
```

### ❌ Все DNS показывают NO_ANSWER в dns-diag

**Причина:** Скорее всего, не установлены `bind-tools`/`bind-dig`.

**Решение:**
```bash
apk add bind-tools     # OpenWrt 25.x
opkg install bind-dig  # OpenWrt 24.x и ниже
```

Без `dig` команда `dns-diag` не может проверить порты, но dnsmasq работает корректно.
