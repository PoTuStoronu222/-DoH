# 🚀 OpenWrt DoH & SmartDNS Optimization Suite (v10.0)[cite: 1]

Комплексный скрипт автоматической настройки отказоустойчивой DNS-инфраструктуры для роутеров под управлением OpenWrt[cite: 1]. Решает проблемы с блокировками, заглушками провайдера, рассинхронизацией времени и падением сервисов из-за нехватки ОЗУ (Out-Of-Memory)[cite: 1].

---

## 📌 Условия установки и требования[cite: 1]

* **Поддерживаемые ОС:** OpenWrt 19.07 / 21.02 / 22.03 / 23.05 и новее (а также сборки на их основе)[cite: 1].
* **Свободное место:** Не менее **2–3 МБ** в `/overlay` для установки `https-dns-proxy`, `ca-certificates` и служебных утилит[cite: 1].
* **Доступ к сети:** Исходное интернет-соединение во время установки (для скачивания пакетов через `opkg`)[cite: 1].
* **Оболочка:** Совместимо со стандартным `ash` (BusyBox) и `bash`[cite: 1].

---

## ⚙️ Как это работает (Архитектура)[cite: 1]

### 1. Гибридный DoH (SmartDNS)[cite: 1]
В системе поднимается 6 параллельных локальных DoH-резолверов (`https-dns-proxy`) на портах `5053–5058`[cite: 1]. В `dnsmasq` включается режим `allservers=1`: запрос параллельно отправляется во все 6 каналов, а клиенту отдаётся самый быстрый ответ[cite: 1].

### 2. Разделение доменных зон (TLD Split)[cite: 1]
Чтобы национальные сервисы (банки, госуслуги, локальные ресурсы) не ломались из-за DoH, запросы к доменным зонам `.ru`, `.su` и `.рф` направляются напрямую на безопасные DNS Яндекс (`77.88.8.8` / порт `5059`)[cite: 1]. Весь остальной мировые трафик шифруется через DoH[cite: 1].

### 3. Защита от заглушек провайдера (Anti-Stub / Bogus-NXDOMAIN)[cite: 1]
Скрипт выполняет контрольный запрос заблокированного ресурса через DNS провайдера, считывает IP-адрес страницы-заглушки и заносит его в `bogus-nxdomain` в `dnsmasq`[cite: 1]. В 04:00 утра Cron автоматически обновляет эти IP[cite: 1]. Если провайдер пытается подсунуть заглушку — `dnsmasq` отбраковывает ответ и принимает настоящий IP из DoH[cite: 1].

### 4. Синхронизация времени и перехват NTP[cite: 1]
DoH критически зависим от точного времени (проверка SSL-сертификатов)[cite: 1]. Скрипт перехватывает весь исходящий NTP-трафик (порт `123`) и перенаправляет его на роутер, а также проводит принудительную синхронизацию часов при старте[cite: 1].

### 5. Оптимизация тяжелых Go-сервисов (OOM Shield)[cite: 1]
Если в системе установлены `tailscale` или `tg-ws-proxy-go`, скрипт внедряет переменные `GOMEMLIMIT=32MiB` и `GOMAXPROCS=1` в их init-скрипты[cite: 1]. Это заставляет сборщик мусора Go работать агрессивнее и не даёт сервисам забирать всю ОЗУ роутера[cite: 1]. Если сервисы не установлены — шаг автоматически пропускается[cite: 1].

## 🧪 Проверка работы после установки

**1. Проверка статуса DoH-резолверов:**

```bash
netstat -lntp | grep https-dns-proxy

```

*(Должны отображаться прослушиваемые порты 5053–5058)*

**2. Проверка резолва через DoH:**

```bash
nslookup google.com 127.0.0.1

```

**3. Проверка генерации правил от заглушек:**

```bash
cat /etc/dnsmasq.d/anti-block.conf

```

## 🔄 Механизм отката (Rollback)

Перед внесением любых изменений скрипт делает полный бэкап конфигураций в `/etc/config/backup-pre-dns-v9` и автоматически формирует персональный скрипт восстановления `/root/rollback-dns.sh`.

### Что делает скрипт отката:

* Восстанавливает исходные файлы конфигурации (`dhcp`, `firewall`, `https-dns-proxy`, `system`, `crontabs`) из бэкапа.
* Удаляет созданные файлы правил (`/etc/dnsmasq.d/anti-block.conf`).
* Удаляет скрипт автообновления и задачи из Cron (`/usr/bin/update-bogus-dns`).
* Возвращает исходные параметры `sysctl` в RAM.
* Перезапускает сетевые службы в исходное состояние.

### Команда отката одной строкой:

```bash
sh /root/rollback-dns.sh && reboot

```
